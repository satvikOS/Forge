# Branch Information

## copilot/create-archdisc-software

This is the default branch for the archdiscv1 repository.

### Purpose
This branch serves as the primary development and release branch for the ArchDisc software project.

### Setting as Default Branch
To set this branch as the default on GitHub:
1. Go to the repository on GitHub: https://github.com/satvikOS/archdiscv1
2. Navigate to Settings > Branches
3. Under "Default branch", click the switch branches button
4. Select `copilot/create-archdisc-software` from the dropdown
5. Click "Update" and confirm the change

Note: You need admin/write access to the repository to change the default branch.
