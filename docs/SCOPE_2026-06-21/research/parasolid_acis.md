# 1:1 Parity Matrix — In-House Forge Kernel vs Siemens Parasolid + Spatial 3D ACIS

**Scope deep-dive, SCOPE_2026-06-21.** Exhaustive functional parity matrix for the Forge native geometry kernel measured against **both** commercial incumbents — **Siemens Parasolid** (the PK functional interface) and **Spatial 3D ACIS Modeler** (the component/husk + API architecture). For every row: what Parasolid does, what ACIS does, what the five reference open kernels (OCCT / CGAL / libfive / PicoGK / Manifold) provide, and the **GAP** the in-house pure-C++ kernel must close.

This document feeds (1) the mission bible, (2) Archie's training-corpus plan, (3) the kernel 1:1-parity plan, and (4) the enterprise UI/UX redesign.

## 0. Ground truth & honesty frame

- **What Forge actually links today.** `forge-kernel/` is a C++20 Node-API `.node` addon linking **OCCT 7.9.3** (20 toolkits: `TKernel TKMath TKG2d TKG3d TKGeomBase TKGeomAlgo TKBRep TKTopAlgo TKShHealing TKPrim TKBO TKBool TKFillet TKOffset TKHLR TKMesh TKDE TKDESTEP TKDEIGES TKDESTL TKDEVRML TKXSBase`) + vendored **planegcs** (2D constraint solver) + header-only Eigen/Boost. Evidence: `KERNEL_UNIFICATION.md §1.1`, `forge-kernel/CMakeLists.txt:80-87`. Two of five capability classes (guaranteed-manifold mesh booleans; implicit/SDF + voxel/lattice) currently live **only in the JS frontend on WASM deps `manifold-3d` + `opencascade.js`** — the deps that must be retired.
- **In-house native kernel** (`forge::native::`) is being built bottom-up alongside OCCT (predicates → mesh → implicit → voxel → B-rep/NURBS). Per `KERNEL_PARITY.md §0`, the in-house mesh boolean (`mesh::meshBooleanNative`) now closes general boundary-crossing booleans (~98–100% random general-position cube pairs, 0 fakes), Manifold-class robustness ceiling (double-precision shared coords), NOT CGAL-exact rationals. B-rep/NURBS in-house (Stage 6) is the multi-year pole and remains OCCT-anchored.
- **Status legend used in the GAP column:** `[HAVE]` = OCCT (linked) or an in-house gate already covers it; `[PARTIAL]` = present but limited scope / robustness / no demanding test; `[GAP]` = no binding / must be built; `[GAP-HARD]` = an industry-multi-year-class problem (e.g. tolerant B-rep, variable-radius blend robustness, healing).
- **Sizing:** Parasolid PK interface ≈ **900+ documented functions** (677 unique `PK_*` symbols counted in the V13 reference index alone); ACIS ≈ **35 husk components** × hundreds of `api_*` functions. Parity = covering the *operation classes* and per-class robustness, not literal symbol count.

## Biggest-gap synthesis (the rows that decide CADGenBench ≥0.85)

The CADGenBench north-star (≥0.85 on **every** dimension) is gated less by the easy analytic/primitive rows (mostly `[HAVE]` via OCCT) and more by the **`[GAP-HARD]` commercial moats** — and, for the no-deps end-state, by re-implementing them in-house rather than on OCCT.

1. **Tolerant modeling (b9) + tolerant booleans (a4) + full heal pipeline (c6).** Per-entity tolerance bands + tolerant intersection/snap is the #1 Parasolid/ACIS moat and the difference between passing/failing imported-STEP CADGenBench cases. In-house repair is currently float, not exact.
2. **Surface-surface intersector → exact intcurves with pcurves (b8) and B-rep-level boolean robustness (a2).** OCCT booleans are bound but acknowledged weaker on degenerate/tangent cases; the in-house mesh boolean is Manifold-class (double-precision), not B-rep-exact. This is the literal core of the kernel.
3. **Face-face + variable-radius + setback blending (a7/a9/a10).** Curvature-continuous (G2) face-face blends, holdline/cliff-edge, propagation, notches, ribs, and conic variable cross-sections — OCCT has no first-class face-face blend; this is a large dedicated engine.
4. **Native history/rollback/marks/partitions (b12) + persistent-ID rebuild (b13/c1).** No reference open kernel ships the Parasolid/ACIS bulletin-board + independent-stream rollback; without robust persistent IDs Forge inherits FreeCAD's topological-naming fragility.
5. **Convergent/facet modeling (a33) + lattice→B-rep (a34).** Unified B-rep ∪ mesh body (analytic + facet faces booleaning/blending together) is a genuine differentiator and aligns with the in-house mesh+brep unification; needed for AM/lightweighting flagships.
6. **Defeature / feature-recognition / midsurface (a25/a26) + deformable modeling (c3).** Auto feature-recognition defeature and midsurface are sim-prep essentials; ADM-class deformable sculpt is the Class-A/industrial-design gap.
7. **Interop completeness: XT/XB + SAT/SAB + JT + AP242-PMI round-trip (c7/c9/c10).** Reading the two kernel-native formats and JT is table stakes for enterprise PLM and for ingesting CADGenBench/Mecado assets; AP242 PMI semantic round-trip is the GD&T-scoring path.
8. **Cellular/general/non-manifold bodies + Euler-operator substrate (a3/c15).** General bodies (cellular, mixed-dimension, non-manifold) plus a formal Euler-operator API are the safe topological foundation everything else stands on — absent from OCCT and must be built into the in-house half-edge.
