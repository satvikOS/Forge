## §0. THE NON-NEGOTIABLES (the discipline that gates every line of work)

These bind all kernel, model, sim, UI, and corpus work. A deliverable that violates any §0 rule is not done.

1. **REAL / DYNAMIC / NO-STUB.** Real implementation only — no MVP, no stub, no fallback, no duplicate engine, no placeholder. Dynamic (transient/modal/forming/motion) over static. If a dep is missing, surface the real error; never paint a fake.

2. **A/B-VERIFIED, TOPOLOGY-SIGNATURE GATED.** Every native op keeps its dependency (OCCT / planegcs / libfive-as-oracle / PicoGK-as-reference / a frozen golden corpus) as the **live default AND A/B parity oracle** until the native path is A/B-proven, then flips behind a per-op gate. **Every topology-changing A/B gate MUST include a topology signature (V/E/F counts + sorted adjacency hash + per-surface-kind histogram) — NOT mass-props alone.** Two different solids can share volume/COM/inertia/AABB; mass-props parity is the #1 silent-failure trap (every kernel audit re-confirms this).

3. **ORACLE-REMOVAL DISCIPLINE.** Delete a dependency only at the very end, only after zero runtime calls under the full regression + CADGenBench, and only against a **frozen golden corpus** built while the oracle still existed. For Parasolid-XT / ACIS-SAT there is *no* OCCT oracle — they require a golden corpus exported once from licensed apps that must survive past deletion.

4. **CI-GREEN GATE.** Monitor CI/CD; advance only when GREEN on all platforms. If red, fix first, then proceed. Keep a Monitor on `gh run list` during multi-batch work.

5. **HARDWARE-CALM — ONE HEAVY STEP AT A TIME.** Mac Studio M4 Max, 36 GB unified RAM. The machine OOMs when training + serve + Electron + Vite + agents stack. **Kernel C++ rebuilds and GPU/MLX training NEVER run concurrently** — the GPU must be free of training before a kernel rebuild, and serve-XOR-train always. Restart `mlx_lm.server` fresh before any eval/demo (output degrades over a long session).

6. **CUA-ONLY E2E.** Archie drives Forge **purely and only via computer-use**: a typed prompt → Archie console → schema-valid `forge.<wb>.<op>(args)` tool-calls → kernel builds → render. Builder scripts and `window.__forge*` composers are scaffolding, not the goal; the canonical e2e is the genuine-CUA spec, headed, watchable, ≥5 cam angles, distinct prompts each run. Manual UI clicks never post to Archie's thread.

7. **STORAGE-SAFE STREAMING (corpus).** All dataset ingest/generation is strictly download→process→delete one-at-a-time, parquet `iter_batches`, accumulator-dedup. **Never `--mask-prompt` on long reasoning corpora** (all-masked → NaN → silent adapter corruption). Early loss-verify + NaN-guard every run. Chat-template on every sample. `bulk_synth` programmatically (millions/run), never agent hand-authoring (~40–60/run).

8. **HONESTY BY CONSTRUCTION.** Where a regime is unverified (turbulent CFD capped AMBER, post-buckling without arc-length, singular re-entrant stress, profile-vs-NURBS GD&T, Parasolid/ACIS with no oracle), the correct output is `{error}` — surface the limit, paint nothing, fabricate no coefficient. Honesty is a trained behavior (DPO ranks standards-grounded ≻ plausible-wrong) and a runtime contract.
