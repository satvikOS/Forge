## 0. TL;DR / honesty headline

- **The overwhelming majority of Archie's *task* training data is SYNTHETIC and
  generated by deterministic Python templating against the in-repo tool
  registries.** No LLM in the loop for those, so there is no model-distillation
  license question for the Forge / Studio / Mech / spec corpora. These are the
  corpora that teach Archie to drive the two apps.
- **The `data/foundational/` corpus (~36.8 GB train, the single largest pile) is
  DIFFERENT: it is built by streaming ~110 real third-party Hugging Face
  datasets** (`scripts/multi_stream*.py`, `cosmopedia_100k_stream.py`,
  `cap3d_stream.py`). Their licenses are **heterogeneous and NOT audited in
  code** — there is **no license-filtering logic in the streamers** (verified:
  `grep -liE 'licen' scripts/multi_stream*.py` → no match). **Several included
  sources are legally questionable for a commercial product** (GPT-distilled
  sets under OpenAI TOS; CC-BY-NC sets; chat logs under custom non-commercial
  agreements; scraped legal text). These are flagged in §6.
- All JSONL data is **gitignored** (`.gitignore:14-19`) — synthetic and
  regenerable; the raw external downloads are deleted after processing
  (storage-discipline rule; `data/foundational/raw/` is empty — verified).
- "Built & validated" vs "targeted" is separated in every section. The big
  legal exposure is the foundational mix, not the engineering corpora.

redistributed.

## 7. Preference / critic corpora (SYNTHETIC, derived) — `data/dpo/`, `data/critic/`

- **`data/dpo/` (140 MB):** `dpo_synth.py` takes first-party *positive* Studio/Mech

  one R-rule (R1 invented id / R2 missing preamble / R3 order / R5 truncated /
  cross-app contamination) — `dpo_synth.py:55-113`. **Default target 50,000 pairs**
  (`:117`). **Fully synthetic, first-party.** Capability: format/coherence
  discipline. *(Note §2 caveat: the Studio side of the source pool is currently
  empty.)*
- **`data/critic/` (85 MB):** `critic_synth.py` turns each DPO pair into a
  critique-training row teaching the 1.5B verifier to name the violated R-rule
  (`critic_synth.py:21-73`). **Default target 50,000** (`:19`). Synthetic,
  first-party. Capability: self-critique / verification.
- **`data/dpo_sft/` (106 MB):** DPO pairs reformatted to SFT (`dpo_to_sft.py`).
- **Validation:** these are **built**; correctness is structural (mutations are
  deterministic), **not human-rated.**

## 9. One-line legal verdict (honest)

The **engineering brain** (Forge / Studio / Mech / spec corpora — what actually
teaches Archie to build and simulate things) is **first-party synthetic and
