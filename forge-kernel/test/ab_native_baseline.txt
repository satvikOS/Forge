# thicken was 19 — a RECORDED DEFECT, now FIXED and lowered to 0 in the same commit.
# PR #64 replaced three BRepPrimAPI_MakePrism sites with forge::occtPrism, and all 19
# failures were the FACE-TYPE census: occtPrism emitted Geom_SurfaceOfLinearExtrusion

# the solids were geometrically identical, only their surfaces were TYPED differently.

# not expose. occtPrism now takes `canonize` (default FALSE, so every other caller is
# unchanged) and the three NativeThickenShell sites pass true, restoring the canonical
# lateral types MakePrism produced. MEASURED, same harness, engine file the only
# variable: 208 passed / 19 failed -> 227 passed / 0 failed, no assertion weakened.
# See implementation/sacrosanct/findings/PR64_CHANGED_THE_FACE_TYPE_CENSUS.md.
